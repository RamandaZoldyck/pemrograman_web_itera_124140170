Deskripsi Program

1. Program Penghitung BMI (`tugas1_bmi.py`)

Program menerima input berat badan dalam kilogram dan tinggi badan dalam meter. Program menghitung BMI menggunakan rumus: berat / (tinggi * tinggi) , kemudian menentukan kategori berat badan dengan percabangan if-elif-else.

2. Pengelolaan Data Nilai Mahasiswa (tugas2_nilai_mahasiswa.py)

Program menyimpan data minimal lima mahasiswa dalam list yang berisi dictionary. Nilai akhir dihitung menggunakan bobot 30% UTS, 40% UAS, dan 30% tugas. Program menentukan grade A-E, menampilkan tabel nilai, serta mencari mahasiswa dengan nilai akhir tertinggi dan terendah.

3. Modul Matematika (math_operations.py dan main.py)

math_operations.py berisi konstanta PI, fungsi luas dan keliling persegi, persegi panjang, dan lingkaran, serta fungsi konversi Celsius ke Fahrenheit dan Kelvin. main.py mengimpor dan menguji seluruh fungsi menggunakan dua cara import yang berbeda.

Cara Menjalankan Program

Buka terminal pada folder proyek. Pastikan Python sudah terpasang, lalu jalankan:

Soal 1 - BMI
python tugas1_bmi.py

Soal 2 - Nilai Mahasiswa
python tugas2_nilai_mahasiswa.py

Soal 3 - Modul Matematika
python main.py
